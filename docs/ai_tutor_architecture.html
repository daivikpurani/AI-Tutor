AI-Tutor Architecture – Quick Reference

Single-page reference: Ingestion → Query Preprocessing → Retrieval & Reranking → Hybrid LLM Routing

  subgraph s1["1. INGESTION LAYER"]
    A1[File Upload: .txt .md .pdf .docx .doc  max 10MB]
    A2[Text Extraction: PyPDF2 / python-docx / direct read]
    A3[Chunking: Semantic or Default boundaries]
    A3p["chunk_size=1500  chunk_overlap=200"]
    A4[Embedding: all-MiniLM-L6-v2]
    A5[Storage: ChromaDB  ai_tutor_documents]
    A1 --> A2 --> A3 --> A4 --> A5
    A3 -.-> A3p
  end

  subgraph s2["2. QUERY PREPROCESSING"]
    B1[Demo check: hardcoded RAG Q&A]
    B2[Injection guard: detect_injection]
    B3["Query compression: Ollama  last 8 msgs  max 600 chars"]
    B4[Multi-query: optional 2-3 variants via Ollama]
    B1 --> B2 --> B3 --> B4
  end

  subgraph s3["3. RETRIEVAL AND RERANKING"]
    C1["Vector search: top_k=12  distance < 2.0"]
    C2["Reranking: ms-marco-MiniLM-L-6-v2  higher=better"]
    C3[Rerank output: top 6 chunks]
    C4[Doc selection: best-matching doc only]
    C5["Quality: good if sim > 0.40 or dist < 2.5"]
    C6["Context build: max 4500 chars  Context N from filename"]
    C1 --> C2 --> C3 --> C4 --> C5 --> C6
  end

  subgraph s4["4. HYBRID LLM ROUTING"]
    D1[Mode: Exploration vs Assessment]
    D2["Exploration: max_ctx=2500 max_gen=400 temp=0.7  Assessment: 6000 600 0.2"]
    D3[Provider order: Ollama then OpenAI then Mock]
    D4[Draft: always try Ollama first]
    D5[Self-check: confidence + missing citations]
    D6["Escalation: conf < 0.72 or < 0.55 OR missing cites → OpenAI"]
    D7[Complexity: Simple/Complex/Unknown for streaming]
    D1 --> D3 --> D4 --> D5 --> D6 --> D7
    D1 -.-> D2
  end

  B4 --> C1
  C6 --> D1
Example: 5000-char doc → ~4 chunks (1500 chars, 200 overlap). Query "what is RAG" → 12 candidates → rerank → top 6 → context ~4500 chars → Ollama draft → if conf < 0.55, escalate to GPT-4o-mini.
